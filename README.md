# 📊 Superstore Sales Data Analysis

Projeto de análise exploratória de dados focado em identificar oportunidades de otimização de vendas, margem de lucro e eficiência operacional em um e-commerce.

## 🔗 Links Úteis
* [Acesse o Notebook completo interativo no Kaggle](Cole_o_Link_do_Seu_Kaggle_Aqui)

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Python
* **Bibliotecas:** Pandas, NumPy, Matplotlib, Seaborn
* **Plataforma:** Kaggle Notebooks

## 📈 Resumo das Descobertas
* **Descontos e Lucratividade:** Descontos superiores a 20% geram margens de lucro negativas.
* **Categoria Destaque:** Produtos da categoria **Technology** entregam a maior rentabilidade.
* **Oportunidade de Melhoria:** A categoria **Furniture** possui volume de vendas alto, porém baixa margem líquida.
